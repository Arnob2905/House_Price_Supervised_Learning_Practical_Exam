# House Price Prediction — Supervised Learning Summary

## Business problem and dataset
The project builds a regression model for a PropTech-style product that needs to estimate a home's sale price from its physical characteristics, quality, facilities and location. The dataset is the Ames Housing `train.csv` file from the Kaggle House Prices competition. It contains 1,460 house records and a continuous `SalePrice` target. This dataset is a benchmark rather than Indian market data, so the model demonstrates the workflow and should not be used to quote real Indian property prices without suitable local training data.

## Preprocessing and feature engineering
The notebook first examines data types, missing values, distributions, skewness, correlations and relationships between key features and `SalePrice`. The original target is positively skewed, so `log1p(SalePrice)` is used for training; predictions are converted back with `expm1()` before reporting price errors. Four columns with more than 80% missing values are removed. Missing values that mean absence are filled with `None` or zero where appropriate, while remaining numeric and categorical gaps are handled by median and most-frequent imputers inside the pipeline. Two unusually large, relatively low-priced homes meeting the assignment's outlier rule are removed. Five features are engineered: `TotalSF`, `HouseAge`, `RemodAge`, `HasGarage` and `HasPool`. Quality ratings are mapped to ordered numeric values; nominal categories are one-hot encoded, including `Neighborhood`, `Exterior1st` and `Exterior2nd`. `Id` is excluded because it is only a record identifier. Skewed, non-negative numeric features are log-transformed, and numeric features are scaled. The `ColumnTransformer` and model pipeline keep transformations consistent for training, evaluation and deployment.

## Models and evaluation
The project compares Linear Regression, Ridge, Lasso, Random Forest and XGBoost using RMSE, MAE and R² on the original USD price scale. It also reports 5-fold cross-validation RMSE, model training time, actual-versus-predicted plots, feature importance and residual diagnostics. In the recorded run, Lasso had the lowest held-out test RMSE at about **$18,884**, MAE about **$13,763**, and R² about **0.9354**. However, the final model is selected by training-only 5-fold cross-validation rather than test score alone. Ridge had the lowest mean CV RMSE at about **$21,803** and was selected for the saved pipeline; its test RMSE was about **$19,480**, MAE about **$14,019**, and R² about **0.9313**. The residual plots show most errors near zero, with a longer negative tail and a few substantial errors.

## Conclusion and limitations
Ridge provides a reasonable balance of validation stability and interpretability for this experiment, while Lasso achieved a slightly better score on the particular test split. Results are estimates from one random split and should be confirmed with additional validation before deployment. Feature coefficients indicate association, not causation. Before real-world use, the model would need representative local data, monitoring, fairness checks, and a process for retraining as housing markets change.
